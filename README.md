# Unity School Redesign

Desktop-first redesign of Unity School's public website.

## Current scope
- Desktop implementation first
- Shared navigation, footer, CSS and JavaScript
- Home, About, Admissions, Academics, Preschool, Elementary, Middle School, Lessons in Living, Student Life, Athletics, Families and Contact/Tour
- Netlify-ready static site
- Legacy redirect map
- No fabricated events or statistics

## Local preview
Serve the repository root with any static HTTP server.

## Deployment
The project is structured for Netlify. The existing Unity School website should remain live until staging review and launch approval.

## Content notes
Live services remain external where appropriate:
- FACTS / RenWeb
- Nutrislice
- Google Calendar
- Current Unity School resources

Photography is represented by local visual placeholders during integration. Replace the files in `assets/images/` with approved Unity School photography before launch.
